# ARPINIA ODYSSEY — PROJECT CONSTITUTION

## 1. CORE DOCTRINE
ARPINIA Odyssey is **ALGORITHM-FIRST** and **AI-ASSISTED**.
- Deterministic algorithms, physics (OpenDrift), and validated ML/CV models generate the investigation truth.
- The LLM acts **strictly as an interpretation layer**. It reads Evidence JSON and translates it to human-readable text. It MUST NOT perform mathematical calculations, spatial queries, or declare guilt independently.

## 2. DOCUMENT HIERARCHY
1. **LEVEL 0 (Constitution):** Repository governance, operating rules, and ownership.
2. **LEVEL 1 (Locked Contracts):** JSON schemas (`packages/contracts/`).
3. **LEVEL 2 (Architecture):** System diagrams, data flow, module contracts.
4. **LEVEL 3 (Product Requirements):** PRD, MVP, definitions of done.
5. **LEVEL 4 (Module Specifications):** API specs, database schemas.
6. **LEVEL 5 (Implementation Plans):** Planned tasks, issues.
7. **LEVEL 6 (Code):** Source code.

If Level 6 contradicts Level 1, **Level 6 is broken and must be fixed.**

## 3. IMMUTABILITY
Frozen documents and contracts cannot be changed without formal review and approval. They represent the locked communication protocols between independent student pods.
